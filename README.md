# SplitEase

SplitEase is a full-stack shared expense tracking application that allows users to create groups, record shared expenses, calculate balances, and settle payments.

## Technology Stack

- **Frontend:** Next.js, React, TanStack Query, Formik / Yup, Tailwind CSS
- **Backend:** Node.js, Express
- **Database:** PostgreSQL, Sequelize
- **Validation:** Joi
